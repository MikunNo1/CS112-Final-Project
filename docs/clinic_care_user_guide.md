# CLINICIAN USER GUIDE
1.	Go to http://127.0.0.1:5000/register
Enter ID ending in 0000
Name, Email, password and select clinician role
2.	Enter ID and Password into the login page
3.	To assign a task, fill in the title, description, due_date, patient_ID and click assign
4.	 To review a submission, locate the submission under submissions review status, choose an outcome, add an optional note and save

# PATIENT USER GUIDE
1.	Go to http://127.0.0.1:5000/register
Enter ID ending in 2022-2028
Name, Email, password and select clinician role
2.	Enter ID and Password into the login page
3.	View Assigned tasks on your dashboard
4.	Choose an acceptable file type under the task, upload it and click submit
5.	View the status of your submission and the doctor’s selected outcome and notes under Submission Status
